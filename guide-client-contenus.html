Transmettre vos contenus et vos fichiers

Envoyez les bons éléments dans le bon contexte, avec une version identifiable et sans exposer de données inutiles.

Guide pratiqueContenu relu · 26.09.2026
Pour qui ?Clients

Préparer les fichiers

Conservez les originaux sur un emplacement de confiance. Regroupez les éléments par usage : textes, images, identité et documents utiles au projet. Donnez des noms compréhensibles, par exemple « page-services-texte-v02 » plutôt que « nouveau-final-final ».

Indiquez ce qui est validé, provisoire ou fourni à titre de référence. Un fichier techniquement lisible peut ne pas être prêt à être utilisé.

Transmettre sans ambiguïté

  1. Vérifiez le nom du projet et le destinataire.
  2. Utilisez l’emplacement ou le canal de partage convenu avec votre interlocuteur. N’envoyez pas les documents du projet dans le forum public.
  3. Ajoutez un court message qui précise le contenu, la version et l’usage attendu.
  4. Signalez les éléments manquants et ce qui remplace une version précédente.
  5. Vérifiez que le transfert est terminé et, pour un lien partagé, que le destinataire prévu peut réellement l’ouvrir.

Si votre accès Workspace propose l’ajout de fichiers, suivez la procédure de transfert. Sans cette action, demandez le canal adapté : les droits de lecture ne donnent pas automatiquement des droits d’import.

Qualité et autorisation d’utilisation

Une capture d’écran ne remplace pas toujours le fichier original, notamment pour une image à retravailler ou un logo. Lorsque vous disposez d’un fichier source exploitable, transmettez-le avec son aperçu.

Précisez l’origine des ressources et les restrictions dont vous avez connaissance. Ne supposez pas qu’un élément trouvé en ligne est réutilisable. En cas de doute, faites vérifier la ressource avant son intégration.

Données sensibles

Retirez les informations qui ne sont pas nécessaires au travail. Ne joignez pas de mots de passe, de codes de récupération ou de fichiers contenant des identifiants techniques. Si un accès à un outil est indispensable, demandez une procédure d’invitation individuelle adaptée.

Exemple de message

« Voici les textes de la page Services, version 02. Ils remplacent la version 01. Le premier bloc est validé ; le dernier paragraphe reste à confirmer. Les images sont des références, pas les fichiers définitifs. »

Vérifier le résultat

Le bon destinataire retrouve les éléments, comprend leur statut et sait quelle version utiliser. Si un envoi a échoué, vérifiez d’abord s’il existe déjà avant de le refaire pour éviter les doublons.

Un fichier manque ensuite ? Consultez retrouver un document ou un livrable.
