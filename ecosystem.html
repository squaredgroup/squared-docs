Quel espace Squared utiliser ?

Choisir le bon point de départ selon ce que vous cherchez à faire.

Guide essentielRévisé · 26.09.2026

Site Squared Group

Utilisez le site public pour découvrir Squared Group, ses services, projets, produits et points de contact. Ce n’est pas votre espace de travail.

Squared Workspace

Utilisez Workspace pour votre collaboration : projets accessibles, missions ou tâches selon votre rôle, documents, livrables, messages et informations de travail qui vous sont ouvertes.

Documentation Workspace →

Squared Help Center

Vous êtes ici. Utilisez le Help Center pour comprendre un produit, suivre une procédure, diagnostiquer un problème, participer au forum ou ouvrir une demande privée.

Squared Build

Build est l’espace consacré aux formations et aux cours Squared. Le Help Center documente son utilisation lorsqu’un parcours est vérifié ; il ne duplique pas les cours.

Vous hésitez encore ?

Pour apprendre, consultez la documentation. Pour une action précise, utilisez les guides pratiques. Pour un dysfonctionnement, démarrez le dépannage guidé. Pour une question générale, utilisez le forum. Si votre cas contient des informations privées, utilisez le support.
