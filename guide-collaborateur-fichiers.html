Organiser les fichiers et les versions d’une mission

Gardez une source identifiable et préparez des fichiers compréhensibles pour la personne qui reprendra le travail.

Guide pratiqueContenu relu · 26.09.2026
Pour qui ?Collaborateurs

Une organisation liée au travail

Rangez les éléments selon le projet et leur usage : ressources reçues, travail en cours, éléments à examiner et remise. Réutilisez l’organisation convenue lorsqu’elle existe ; ne créez pas une arborescence parallèle que vous êtes seul à connaître.

Le nom d’un dossier ou d’un fichier ne constitue pas une protection. Les informations confidentielles doivent rester dans un espace autorisé, avec les bons accès.

Identifier une version

Utilisez un nom compréhensible et stable : projet ou sujet, type de contenu et version. Exemple de convention à adapter au projet : « accueil-maquette-v03 ». Ajoutez une date lorsqu’elle apporte une information utile, sans multiplier les codes opaques.

Une version remise pour examen doit être distinguée du fichier que vous continuez à modifier. Ne remplacez pas discrètement une version en cours de validation.

Avant de partager

  1. Supprimez uniquement les éléments de travail clairement inutiles et dont vous êtes autorisé à disposer.
  2. Vérifiez que les liens et fichiers associés sont présents.
  3. Indiquez le fichier de référence et ce qui peut être modifié.
  4. Contrôlez l’accès du destinataire, sans élargir le partage à tout le monde.
  5. Ajoutez une courte note si l’ouverture exige un outil, une dépendance ou une étape particulière.

Éviter les doublons

Avant de créer une nouvelle copie dans Workspace, vérifiez l’élément déjà partagé. Un problème de visibilité peut venir d’un filtre ou d’une permission. Le résoudre en important une copie peut produire deux versions concurrentes.

Pour une nouvelle version de fichier, suivez la méthode réellement prévue pour l’élément concerné ; ne supposez pas qu’une action d’ajout remplace automatiquement l’ancien fichier.

Préparer la reprise

Une personne qui n’a pas suivi la mission doit pouvoir comprendre l’état du travail : version utilisable, limites connues, décision attendue et prochaines actions. Laissez une note de passation concise plutôt que de compter sur la mémoire d’une conversation.

Résultat attendu

Une source de référence est identifiable, les remises ne se contredisent pas et le travail peut être repris sans recherche dans plusieurs dossiers personnels. Consultez aussi terminer une mission.
