FAQ

Réponses courtes aux questions les plus fréquentes sur le Help Center, le support, la communauté et les produits Squared.

GuideMis à jour · 18.09.2026
Comment accéder au Help Center ?

Le centre d’aide est publié sur docs.squaredgroup.studio. Il est public : ne considérez jamais une page comme un espace confidentiel.

Où poser une question ?

Utilisez la page Communauté, puis GitHub Discussions pour les questions générales, les idées et les échanges.

Où signaler un bug ?

Utilisez Support puis le ticket public GitHub si le problème est reproductible et ne contient aucune donnée sensible.

Que faire si ma demande contient des données privées ?

N’utilisez ni Discussions ni Issues. Passez par le canal officiel Squared Group indiqué dans la page Support.

Qui peut modifier la documentation ?

Les changements sont versionnés dans GitHub. Une correction doit rester petite, vérifiable et conforme aux règles de contribution. La sidebar est centralisée : elle ne doit jamais être recopiée dans une page.

Pourquoi le thème clair est-il le thème par défaut ?

Le Help Center privilégie la lecture longue et la neutralité documentaire. Le thème sombre reste disponible et le choix est mémorisé localement dans le navigateur.

Je ne trouve pas une réponse

Recherchez avec plusieurs formulations, consultez les Guides rapides, puis posez la question dans la communauté. Si la question revient régulièrement, elle doit ensuite devenir une vraie page d’aide.
