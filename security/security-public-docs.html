Préparer un contenu pour une publication publique

Vérifiez le texte, les captures, les liens et les exemples avant d’ajouter une page au Help Center.

Référence pratiqueContenu relu · 26.09.2026
Pour qui ?Intervenants autorisés sur les supports Squared

Considérer la source comme publique

Le dépôt public et les pages de documentation peuvent être lus hors de votre équipe. Une page non présente dans le menu reste publique si elle est servie sans contrôle d’accès. Une règle d’indexation n’est pas un mécanisme de confidentialité.

Relire le contenu

  1. Retirez les mots de passe, codes, clés et liens d’accès privés.
  2. Remplacez les exemples client par des données de démonstration.
  3. Vérifiez les captures, les noms de fichiers, les adresses et les commentaires.
  4. Supprimez les détails internes qui ne sont pas nécessaires à l’explication.
  5. Vérifiez les destinations des liens et les fichiers proposés au téléchargement.

Une capture doit expliquer une action, pas exposer un vrai compte pour paraître plus réaliste.

Décrire les permissions sans les contourner

Un guide peut expliquer qu’une action demande une autorisation et comment demander sa vérification. Il ne doit pas fournir une procédure de contournement, une clé privilégiée ou un exemple qui désactive la protection pour faire fonctionner l’écran.

Distinguer faits et projets

Une fonctionnalité envisagée ne doit pas être décrite comme disponible. Précisez la plateforme et le contexte lorsque les écrans diffèrent. Une méthode recommandée doit rester distincte d’une condition commerciale ou contractuelle réellement adoptée.

Valider et publier

Faites relire le besoin couvert, l’exactitude et le périmètre public. Vérifiez les liens et l’affichage. Après publication, ouvrez la page réelle et contrôlez les fichiers accessibles. Une mention « réservé aux membres » dans le texte ne rend pas un fichier privé.

Exposition découverte après publication

Ne diffusez pas à nouveau la donnée pour signaler le problème. Indiquez l’emplacement par un canal privé et suivez la procédure d’incident. Préservez les faits utiles sans multiplier les copies du contenu sensible.
