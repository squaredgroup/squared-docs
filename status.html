Hébergement & domaine

Le Help Center est publié via GitHub Pages sur docs.squaredgroup.studio. Le DNS est géré côté domaine Squared Group et le certificat HTTPS est provisionné par GitHub Pages.

Community & Support

Les comptes, discussions, réponses, notifications et tickets privés reposent sur le projet Supabase dédié Squared Help Center, hébergé en région Paris.

Ce qui est réellement monitoré

Cette page reflète les vérifications effectuées sur le Help Center. Elle ne prétend pas mesurer en temps réel tous les produits Squared qui ne disposent pas encore d’un monitoring automatisé.

Vous constatez un incident ?

Si un problème affecte plusieurs utilisateurs ou bloque un parcours critique, utilisez le support privé avec l’heure, le périmètre, le symptôme et l’impact observé.

Besoin du détail technique ?

La page États des serveurs teste directement les principaux composants depuis votre navigateur.
