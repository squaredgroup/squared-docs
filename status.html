Help Center

Opérationnel. Si vous consultez cette page depuis le domaine officiel, le frontend GitHub Pages et le domaine sont accessibles depuis votre connexion actuelle.

GitHub Pages & dépôt

Le site dépend de GitHub Pages pour l’hébergement et de GitHub pour le dépôt, Issues et Discussions. Pour un incident GitHub global, consultez la page de statut officielle de GitHub.

GitHub Status ↗

Domaine & HTTPS

Le domaine personnalisé est docs.squaredgroup.studio. Le DNS est géré depuis Wix et le certificat HTTPS est provisionné par GitHub Pages.

Squared Workspace

Le Help Center ne réalise pas encore de monitoring automatique de Squared Workspace. L’absence d’alerte ici ne doit pas être interprétée comme une mesure temps réel de l’ERP.

Transparence

Cette page ne doit jamais afficher un statut « opérationnel » fictif pour un service qui n’est pas réellement monitoré.

Signaler un incident

Pour un problème Help Center, utilisez le Support. Pour une panne affectant plusieurs utilisateurs, documentez l’heure, le périmètre, le symptôme et l’impact avant toute correction.
