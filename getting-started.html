Bien démarrer avec le Help Center

Trouver le bon niveau d’aide sans avoir besoin de connaître l’organisation interne de la documentation.

Guide essentielRévisé · 24.09.2026

Commencez par ce que vous voulez obtenir

Vous n’avez pas besoin de connaître le nom exact d’un module. Recherchez une action (« activer mon compte », « retrouver un document ») ou un symptôme (« je ne peux pas me connecter », « mon livrable n’apparaît pas »).

Choisir le bon parcours

  • Je veux apprendre : ouvrez la documentation du produit et suivez les guides liés.
  • Je veux faire quelque chose : utilisez un guide pratique ou un parcours.
  • Quelque chose ne fonctionne pas : démarrez le dépannage guidé.
  • J’ai une question générale : utilisez le forum.
  • Mon cas contient des informations privées : utilisez le support privé.

Obtenir de meilleurs résultats de recherche

Décrivez le résultat attendu ou le message observé. « Workspace connexion » est moins précis que « invitation Workspace expirée » ou « document absent dans mon projet ».

Sur ordinateur, ⌘K ou Ctrl+K ouvre la recherche. Sur mobile, utilisez Rechercher dans la barre de navigation.

Ce qui ne doit pas être publié

Ne placez jamais dans une discussion publique un mot de passe, token, code d’invitation, code de récupération, document client ou information personnelle non nécessaire. Un lien difficile à deviner n’est pas un espace privé.

Points de départ recommandés

  • Squared Workspace pour les accès, projets, tâches, documents et collaboration.
  • Wix Studio pour les sites et leur maintenance.
  • Design System pour les règles d’interface.
  • Sécurité pour les accès, secrets et données publiques.
