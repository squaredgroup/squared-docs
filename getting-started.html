Bien démarrer avec le Help Center

Trouvez une réponse et choisissez le bon parcours sans connaître l’organisation interne de Squared.

Commencez par ce que vous voulez obtenir

Le Help Center explique comment utiliser les espaces Squared et comment résoudre les difficultés courantes. Vous pouvez lire les guides publics sans publier votre situation. Un compte sert notamment à participer au forum et à suivre vos demandes privées ; il ne vous donne pas automatiquement accès à Workspace ou à une formation Build.

Choisir votre point de départ

  1. Ouvrez Votre parcours.
  2. Choisissez votre besoin : démarrer un projet client, travailler comme collaborateur, utiliser Workspace ou suivre une formation.
  3. Commencez par la première étape utile, puis suivez les liens vers les actions suivantes.
  4. Si vous connaissez déjà votre problème, utilisez plutôt les guides pratiques ou le dépannage guidé.

Pour identifier les différents supports et leurs comptes, consultez Quel espace Squared utiliser ?.

Rechercher une réponse précise

Saisissez le nom du produit, de l’action ou le message rencontré. « Document absent dans mon projet » est plus précis que « problème ». La recherche peut présenter plusieurs types de sources ; vérifiez leur intitulé avant de choisir un résultat. Un sujet de discussion et une procédure de référence n’ont pas le même rôle.

Sur ordinateur, utilisez ⌘K ou Ctrl+K. Sur mobile, sélectionnez Rechercher. Si une recherche est annoncée comme partielle, ses résultats ne prouvent pas l’absence de toute autre réponse.

Choisir entre forum et support

Le forum convient à une question générale dont la réponse peut aider d’autres personnes. Le support privé convient à un compte, un accès ou un contexte confidentiel. Avant de poser la question, rassemblez le produit, la page, le résultat attendu, le résultat observé et les vérifications déjà faites.

Ne publiez jamais de mot de passe, de lien d’invitation complet, de code de récupération ou de document client dans le forum. Une capture peut aussi révéler des informations privées.

Lorsque vous avez trouvé une réponse

Vérifiez que le guide concerne votre rôle et votre plateforme. Réalisez les étapes dans l’ordre, puis contrôlez le résultat attendu. Si une commande n’est pas visible, consultez le cas particulier indiqué au lieu de contourner une permission.

Le glossaire explique les termes utilisés. Pour reprendre un échange privé déjà ouvert, consultez Préparer et suivre une demande privée.
