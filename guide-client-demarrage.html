Préparer le démarrage de votre projet

Rassemblez les informations utiles et clarifiez la prochaine étape avant le début de la production.

Guide pratiqueContenu relu · 26.09.2026
Pour qui ?Clients

Avant le démarrage

Préparez le document de cadrage ou la proposition acceptée, le nom de votre interlocuteur et les informations déjà transmises. Ce guide aide à organiser le lancement ; il ne remplace pas les conditions de votre projet.

Préparer votre dossier

  1. Décrivez l’objectif : le problème à résoudre, les personnes concernées et le résultat souhaité. « Refaire le site » est moins précis que « permettre de comprendre nos services et de demander un devis ».
  2. Rassemblez les éléments existants : textes, identité visuelle, fichiers sources utilisables et références. Signalez ce qui manque ou nécessite une validation.
  3. Identifiez la personne qui centralisera les retours et celle qui prendra les décisions. Si plusieurs personnes interviennent, précisez leurs responsabilités.
  4. Indiquez les contraintes connues : date liée à un événement, contenu en attente, dépendance à un prestataire ou disponibilité réduite.
  5. Confirmez avec votre interlocuteur le canal de transmission et la prochaine étape attendue.

Votre première visite dans Workspace

Après activation de votre accès, ouvrez le projet partagé. Vérifiez son titre, son objectif et les éléments disponibles. Une rubrique vide peut simplement ne pas encore contenir de données partagées ; elle ne prouve pas que le projet n’a pas commencé.

Si le projet attendu manque, notez le compte utilisé et le nom du projet, puis demandez une vérification du partage. Ne créez pas une seconde fiche et ne demandez pas un accès à toute l’organisation.

Exemple de message de lancement

« Objectif : clarifier nos offres. Interlocuteur : la personne désignée pour le projet. Textes disponibles dans le dossier convenu ; les photos arriveront après validation. Décision attendue : confirmer les contenus nécessaires pour la première proposition. »

Cet exemple est un modèle de formulation, pas une description d’un projet réel.

Le démarrage est prêt lorsque…

L’objectif est compris, les éléments manquants sont identifiés et chacun sait quelle action vient ensuite. Un document encore à fournir peut rester ouvert s’il a un responsable et une étape clairement définis.

Une information n’est pas encore décidée

Signalez-la explicitement. Ne considérez pas une date ou une prestation comme confirmée parce qu’elle apparaît dans un échange préparatoire. Faites préciser le point dans le cadre de votre projet avant de vous appuyer dessus.
