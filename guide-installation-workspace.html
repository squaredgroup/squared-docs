Installer ou mettre à jour Workspace

Choisir entre portail web et application native, puis vérifier les étapes après l’installation.

Guide pratique4 min
Quand utiliser ce guide

Vous avez reçu une invitation ou une version de test et ne savez pas par où commencer.

Les étapes à suivre

  1. 01

    Choisir le support

    Le portail web s’ouvre dans un navigateur sans installation native. Si votre invitation vise l’application iPhone, iPad ou Mac, utilisez le parcours indiqué pour cet appareil.

  2. 02

    Vérifier la version proposée

    Pour une bêta, ouvrez l’invitation TestFlight sur l’appareil destinataire et installez uniquement la version qui y est disponible. Une version expirée doit être remplacée par une invitation ou une build valide.

  3. 03

    Séparer installation et accès

    L’ouverture de l’application ne confirme pas l’activation de votre espace. Utilisez ensuite votre invitation ou votre compte Workspace existant.

  4. 04

    Documenter un échec

    Notez l’appareil, sa version système, la version de l’application si affichée et le message exact. N’envoyez pas votre code d’invitation.

Résultat attendu

Vous savez quelle version utiliser et si le blocage se situe à l’installation ou à la connexion.

Si le problème continue

Si la version attendue n’est pas proposée ou si l’ouverture échoue, envoyez ces informations au support privé et indiquez si le portail web fonctionne.
