Identifier les responsabilités et les sources de données

Évitez les copies divergentes et les dépendances invisibles entre modules.

Référence pratiqueContenu relu · 26.09.2026
Pour qui ?Intervenants autorisés sur les supports Squared

Repérer les frontières

Pour un comportement donné, identifiez l’interface, la règle métier, la source de données et le service externe éventuel. Une modification d’affichage ne doit pas contourner un contrôle d’accès imposé par le serveur.

Séparer les responsabilités ne signifie pas créer un module supplémentaire pour chaque ligne. L’organisation doit aider à comprendre et tester les changements.

Choisir une source de référence

Une règle importante doit avoir un emplacement de référence. Dans le Help Center, les guides versionnés et les articles administrables sont des sources distinctes : un index de recherche ne doit pas devenir une deuxième copie éditoriale indépendante.

Pour une donnée affichée, distinguez l’état local, la réponse du serveur et le contenu éventuellement mis en cache. Une copie locale n’est pas une preuve d’enregistrement distant.

Évaluer une modification

  1. Identifiez les lecteurs et les producteurs de la donnée.
  2. Recherchez les noms de champs et les identifiants utilisés.
  3. Listez les écrans, tests et intégrations qui en dépendent.
  4. Décrivez le comportement en cas d’absence, d’erreur ou de réponse ancienne.
  5. Préparez une évolution compatible ou une migration explicitement autorisée.

Dépendance indisponible

Une panne partielle doit produire un état compréhensible. Ne transformez pas une réponse vide due à une erreur en affirmation qu’aucune donnée n’existe. Préservez les protections lors d’une déconnexion et évitez de réafficher tardivement des résultats privés.

Documenter les décisions

Conservez la raison d’une dépendance, les limites connues et les conditions de remplacement. Ne publiez pas des informations d’infrastructure sensibles dans une documentation publique. Les tests doivent couvrir les frontières affectées, pas seulement le rendu final.
