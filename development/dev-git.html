Développement — Git & branches

Conventions de branches, commits et historique pour garder les changements lisibles.

GuideMis à jour · 18.09.2026

Commits

Un commit représente une intention cohérente. Exemples : feat:, fix:, docs:, refactor:.

Branches

Utiliser une branche pour les changements qui nécessitent validation ou expérimentation. Éviter de mélanger plusieurs sujets sans lien dans la même branche.

Historique

Les messages doivent expliquer ce qui a changé de manière exploitable. Un bon historique facilite rollback, audit et compréhension.
