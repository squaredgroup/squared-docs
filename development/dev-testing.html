Développement — Tests & QA

Choisir les contrôles adaptés au risque et vérifier le comportement réel avant release.

GuideMis à jour · 18.09.2026

Niveaux de test

Tests unitaires pour les règles isolées, intégration pour les interactions entre modules, tests de parcours pour les scénarios utilisateurs critiques.

QA manuelle

Vérifier appareils, rôles, états vide/erreur, permissions, réseau lent et données réalistes mais non sensibles.

Régression

Une correction doit tester le problème initial et les zones proches susceptibles d’être affectées.

Preuve

Un test utile produit un résultat observable. Documenter les cas importants plutôt que « ça a l’air bon ».
