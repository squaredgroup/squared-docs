# Code de conduite — Squared Community

Squared Community doit rester utile, professionnelle et accessible.

## Attendu

- rester respectueux et factuel ;
- décrire les problèmes clairement ;
- rechercher avant de publier un doublon ;
- partager les solutions qui peuvent aider d’autres personnes ;
- accepter les corrections et désaccords techniques sans attaque personnelle ;
- protéger les informations confidentielles.

## Non accepté

- harcèlement ou attaques personnelles ;
- spam ou publicité hors sujet ;
- publication de données privées ou secrets ;
- contenu illégal ou dangereux ;
- détournement volontaire des sujets de support ;
- contournement des règles d’accès ou de sécurité.

Les mainteneurs peuvent éditer, verrouiller ou supprimer un contenu qui ne respecte pas ces règles, et restreindre la participation lorsque cela est nécessaire.
