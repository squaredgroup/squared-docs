Confidentialité du support

Comprendre ce qui reste privé dans les tickets support et ce qui ne doit jamais être publié dans le forum public.

GuideMis à jour · 18.09.2026

Ce qui est privé

Les tickets créés dans la page Support sont protégés côté backend : le demandeur et l’équipe support habilitée peuvent les consulter. Les autres membres ne peuvent pas les lire.

Ce qui est public

Les discussions du forum, profils publics et réponses de communauté doivent être considérés comme publics. Une URL peu diffusée n’est pas une mesure de confidentialité.

Secrets et accès

Ne partagez jamais de mot de passe, clé API, token ou code d’accès, même dans un ticket support. Si un secret doit être remplacé, utilisez une procédure de rotation plutôt que de le transmettre.

Données client

Limitez les informations à ce qui est strictement nécessaire au diagnostic. Évitez les exports complets, documents contractuels ou données personnelles lorsque quelques éléments anonymisés suffisent.
