Comprendre les mots utilisés chez Squared

Un vocabulaire commun pour distinguer les personnes, les espaces de travail, les documents et les décisions.

RéférenceContenu relu · 26.09.2026
Pour qui ?Tous les membres

Personnes et organisation

Membre : personne disposant d’un compte dans le service concerné. Le mot ne désigne pas automatiquement un salarié, un associé ou un abonné payant.

Client : personne ou organisation qui collabore avec Squared dans le cadre d’un projet ou d’une prestation. Son espace montre les éléments explicitement autorisés.

Collaborateur : personne participant à un travail confié ou organisé avec Squared. Le rôle dans un outil ne remplace pas le cadre contractuel applicable.

Organisation : contexte auquel sont rattachés des membres et des données. Pôle : regroupement opérationnel de responsabilités. Une rubrique de l’outil n’établit pas, à elle seule, l’existence d’une société distincte.

Rôle : catégorie d’accès d’une personne. Permission : action ou périmètre autorisé. Deux comptes portant un intitulé proche peuvent avoir des droits différents.

Travail

Projet : ensemble organisé autour d’un objectif et d’un résultat. Mission : responsabilité ou ensemble de travaux à mener dans un périmètre. Tâche : action concrète à réaliser et à vérifier.

Brief : informations de départ qui précisent le résultat attendu, le contexte, les contraintes et les critères de réussite. Jalon : étape de référence dans un projet. Échéance : date attendue pour un élément.

Responsable : personne chargée de suivre un élément. Elle n’a pas nécessairement le pouvoir de valider tous les changements. Validation : décision explicite sur un élément et une version donnés. Une lecture, une notification marquée comme lue ou une tâche terminée ne vaut pas automatiquement validation.

Documents et versions

Document : fichier ou information utilisée dans le travail. Livrable : résultat préparé pour être remis ou examiné. Version de fichier : état d’un contenu. Version d’enregistrement : numéro technique utilisé pour suivre les modifications d’une fiche ; ce numéro ne décrit pas nécessairement la version du fichier joint.

Brouillon : contenu encore en préparation. Partagé : rendu accessible à un public identifié. Archivé : retiré du travail actif selon le fonctionnement de l’outil ; ce n’est pas une promesse de conservation illimitée ni une suppression définitive.

Assistance et formation

Ticket ou demande privée : échange d’assistance associé à votre compte. Discussion : sujet du forum, susceptible d’être public. Incident : problème déclaré affectant un service. Mesure de service : observation technique à un moment donné, pas une garantie pour chaque appareil.

Formation, module, leçon : niveaux d’organisation de l’apprentissage dans Build. Carnet : vos notes, favoris et informations de progression. Une progression locale enregistrée dans un navigateur n’est pas automatiquement synchronisée entre appareils.

Un intitulé reste ambigu

Consultez le guide du module avant d’agir. Dans une demande d’aide, recopiez le libellé exact et précisez la page : « version du livrable » et « version d’enregistrement » ne désignent pas toujours la même chose.
