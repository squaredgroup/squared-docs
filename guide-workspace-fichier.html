Ajouter ou ouvrir un fichier dans Workspace

Reliez le bon fichier au bon élément et vérifiez le transfert avant de supprimer une copie de travail.

Guide pratiqueContenu relu · 26.09.2026
Pour qui ?Membres disposant des accès requis

Workspace web : les commandes et les accès peuvent différer dans les applications natives.

Choisir le bon emplacement

Un fichier doit être rattaché à l’élément prévu : document, livrable ou contrat selon sa nature. Avant tout transfert, vérifiez le projet, la version et les personnes qui doivent y accéder. Le nom de la rubrique ne garantit pas à lui seul la confidentialité.

Ouvrir un fichier existant

Ouvrez la fiche correspondante puis Ouvrir le fichier lorsque la commande est présente. Vérifiez le document ouvert, son nom et son contenu. Si aucun fichier n’est rattaché ou si le téléchargement échoue, ne supposez pas qu’il a été supprimé : faites vérifier la fiche et les permissions.

Ajouter un fichier autorisé

  1. Ouvrez le détail du document, livrable ou contrat concerné.
  2. Ouvrez Autres actions, puis Ajouter un fichier si votre compte le permet.
  3. Dans la fenêtre, choisissez le Fichier à transmettre.
  4. Vérifiez son nom, sa version et l’absence de données inutiles ou de secrets.
  5. Sélectionnez Téléverser une seule fois, puis attendez la confirmation.
  6. Rouvrez le fichier depuis la fiche pour vérifier que le bon contenu est accessible.

Le portail web contrôle la taille sélectionnée avant l’envoi et peut signaler un fichier trop volumineux. Respectez la limite réellement indiquée ; d’autres restrictions du service peuvent s’appliquer.

Remplacement et versions

Avant d’ajouter un fichier sur une fiche qui en contient déjà un, confirmez si l’opération doit compléter ou remplacer l’élément attendu. Ne supposez pas qu’un historique de toutes les pièces sera conservé automatiquement. Conservez les versions nécessaires dans l’emplacement autorisé et décrivez clairement celle qui est remise.

Transfert interrompu ou commande absente

Gardez votre copie de travail. Vérifiez la connexion et la fiche avant un nouvel essai afin d’éviter un doublon. Une commande absente correspond parfois à une permission de lecture seule ; demandez alors le canal de remise prévu, pas une élévation générale de rôle.

Pour un fichier attendu mais introuvable, utilisez le guide de recherche d’un document. Pour une remise client, consultez la fin de projet.
