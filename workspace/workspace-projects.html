Suivre l’avancement d’un projet

Retrouvez un projet et reliez son état aux tâches, documents et livrables effectivement visibles.

Guide pratiqueContenu relu · 26.09.2026
Pour qui ?Utilisateurs de Workspace web

Workspace web : les commandes et les accès peuvent différer dans les applications natives.

Avant de commencer

Vous devez avoir accès au projet. Le nom seul peut être ambigu : utilisez aussi le client, le contexte ou la référence transmis par votre interlocuteur. Ce guide porte sur la lecture et le suivi ; modifier les données exige une autorisation distincte.

Ouvrir le projet attendu

  1. Ouvrez Projets depuis votre navigation ou le catalogue des espaces.
  2. Utilisez Rechercher dans la liste avec une partie du titre.
  3. Ouvrez Filtres et tri si nécessaire. Vérifiez le Statut et le Périmètre ; un filtre limité à vos affectations peut masquer le projet recherché.
  4. Sélectionnez la ligne du projet pour ouvrir son détail.
  5. Lisez sa description, son statut, son échéance et les autres informations affichées.

Si plusieurs projets portent un nom proche, ne choisissez pas uniquement le premier résultat. Confirmez le contexte avant d’envoyer un commentaire ou de modifier une information.

Comprendre l’avancement

Dans le détail, les sections de Tâches, Livrables et Documents permettent d’ouvrir des éléments liés lorsqu’ils sont chargés et visibles. Une section vide peut correspondre à un accès limité ou à des données non disponibles dans la session ; elle ne prouve pas qu’aucun travail n’existe.

Pour savoir ce qui vous attend, distinguez une tâche qui vous est affectée, une échéance et une demande de validation. Le statut du projet donne une indication d’ensemble, pas une preuve que chaque fichier a été accepté.

Mettre à jour une information autorisée

Si Modifier est disponible et que le changement entre dans votre périmètre, vérifiez les champs avant de sélectionner Enregistrer. Attendez la confirmation puis relisez le détail. Une nouvelle échéance ou un changement de périmètre doit aussi être confirmé avec les personnes concernées ; changer une date dans un outil ne constitue pas à lui seul un accord.

Un projet n’apparaît pas

Retirez les filtres, vérifiez le compte et recherchez un autre mot du titre. Suivez ensuite le guide du projet invisible. Transmettez le contexte attendu en privé sans créer un projet de remplacement.

Résultat attendu

Vous avez identifié le bon projet, les informations réellement accessibles et votre prochaine action. Pour remettre un commentaire, utilisez le guide des retours client ; pour exécuter une action, ouvrez Tâches.
