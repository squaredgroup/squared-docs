Créer et suivre une tâche

Décrire une action suffisamment claire pour qu’elle puisse être comprise, exécutée puis réellement terminée.

Guide WorkspaceRévisé · 24.09.2026

Une tâche doit être actionnable

Évitez les titres comme « Site », « Client » ou « À voir ». Commencez par une action : « Corriger le menu mobile », « Valider les textes » ou « Préparer le livrable final ».

Les informations utiles

  • Contexte : projet ou mission concernés.
  • Responsable : lorsque l’action doit être portée par une personne.
  • Statut : état réel de l’exécution.
  • Échéance : uniquement lorsqu’une date a un sens.
  • Critère de fin : ce qui permet de dire objectivement que le travail est terminé.

Utiliser les statuts correctement

À faire : pas commencé. En cours : réellement traité. Bloqué : une dépendance empêche d’avancer. En validation : un contrôle est attendu. Terminé : le résultat demandé est atteint.

Quand une tâche est bloquée

Indiquez la dépendance ou la décision attendue au lieu de laisser la tâche « en cours ». Si le blocage vient d’un accès ou d’un document absent, utilisez le guide correspondant avant de dupliquer l’objet.

Avant de marquer Terminé

Vérifiez le résultat, les éventuelles validations et les éléments associés. Une tâche envoyée à quelqu’un n’est pas nécessairement terminée.
