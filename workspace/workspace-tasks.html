Créer et mettre à jour une tâche

Passez d’une action à réaliser à une fiche enregistrée, puis vérifiez son état sans créer de doublon.

Guide pratiqueContenu relu · 26.09.2026
Pour qui ?Utilisateurs de Workspace web

Workspace web : les commandes et les accès peuvent différer dans les applications natives.

Ce qu’il faut préparer

Une tâche doit préciser une action et son résultat observable. « Vérifier les liens du footer sur mobile » est plus exploitable que « Site ». Préparez le projet concerné, le responsable et l’échéance lorsqu’ils sont connus. La création et la modification dépendent de vos droits.

Créer une tâche dans le portail web

  1. Ouvrez Tâches, puis Nouvelle tâche si cette commande est proposée.
  2. Renseignez Tâche et une Description qui explique le résultat attendu, les contraintes et les ressources utiles.
  3. Choisissez le Projet, le Responsable et l’Échéance lorsqu’ils s’appliquent. Ne sélectionnez pas une personne au hasard pour remplir un champ.
  4. Vérifiez Statut et Priorité. Utilisez les choix présentés par l’interface ; une priorité urgente doit correspondre à une situation réellement discutée.
  5. Sélectionnez Enregistrer une seule fois et attendez le retour de l’interface.
  6. Retrouvez la tâche dans la liste, ouvrez son détail et contrôlez les informations sauvegardées.

Modifier une tâche existante

Recherchez-la dans la liste, ouvrez le détail puis Modifier. Vérifiez que vous intervenez sur la bonne tâche avant de changer un statut ou une échéance. Enregistrez, puis relisez la fiche. Si le portail vous demande d’actualiser le détail, chargez la version récente avant de recommencer : un autre changement peut avoir eu lieu.

Terminer, bloquer et faire valider

La commande Terminer peut apparaître sur une tâche modifiable qui n’est pas achevée. Utilisez-la lorsque le résultat demandé est effectivement produit. Si une validation reste nécessaire, transmettez le travail selon le parcours de remise : terminer votre action ne valide pas automatiquement le livrable.

En cas de blocage, expliquez ce qui manque et l’impact sur la suite. Le statut seul ne remplace pas un signalement utile.

En cas d’erreur d’enregistrement

Sans connexion, la fenêtre signale que la saisie doit rester ouverte : ce n’est pas une file d’attente de synchronisation automatique. Ne fermez pas l’onglet avant d’avoir conservé votre texte dans un emplacement autorisé.

Si l’interface confirme l’enregistrement mais demande d’actualiser la liste, ne recréez pas la tâche. Rechargez la liste lorsque le réseau revient et recherchez le titre. Consultez les saisies non enregistrées si la situation reste ambiguë.
