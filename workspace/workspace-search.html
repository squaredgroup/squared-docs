Rechercher une page ou un élément dans Workspace

Trouvez les données autorisées et comprenez la différence entre résultats chargés et recherche élargie.

Guide pratiqueContenu relu · 26.09.2026
Pour qui ?Utilisateurs de Workspace web

Workspace web : les commandes et les accès peuvent différer dans les applications natives.

Ouvrir la recherche

Sélectionnez Recherche dans l’en-tête ou utilisez ⌘K sur Mac et Ctrl+K sur les autres claviers compatibles. Dans Recherche Workspace, saisissez une partie du titre d’un projet, d’une tâche, d’un document ou d’une page.

Une formulation courte et spécifique fonctionne mieux qu’un récit complet. Utilisez le nom de l’élément, pas le contenu confidentiel d’un document.

Examiner les premiers résultats

  1. Saisissez quelques mots distinctifs.
  2. Repérez le type de résultat pour distinguer une page, un projet, une tâche ou un document.
  3. Sélectionnez le résultat, ou utilisez les flèches puis Entrée.
  4. Vérifiez le contexte dans la fiche ouverte avant d’agir.

La première recherche utilise notamment les données déjà chargées dans la session. Un résultat absent n’est donc pas une preuve de suppression.

Élargir aux données autorisées

La commande Étendre aux autres données autorisées demande des informations supplémentaires aux domaines concernés. Attendez la fin du chargement et lisez les éventuels avertissements. Afficher plus de résultats permet de consulter la suite lorsqu’elle est proposée.

Une erreur de chargement peut donner des résultats partiels. Aucun élargissement ne doit contourner vos permissions ni rendre accessibles les données d’un autre client.

Chercher dans une liste précise

Pour un élément déjà rattaché à un domaine, ouvrez sa liste et utilisez Rechercher dans la liste. Contrôlez les filtres de statut et de périmètre. Cette recherche locale et la recherche globale n’ont pas exactement la même portée.

Rien ne correspond

Essayez un autre mot du titre, retirez un filtre et vérifiez le compte. Demandez ensuite une vérification du contexte ou du partage, en indiquant ce que vous cherchez et les contrôles effectués. Ne recréez pas un document ou une tâche pour compenser une recherche infructueuse.
