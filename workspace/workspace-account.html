Modifier votre profil et vos préférences

Mettez à jour les informations du bon compte et vérifiez la confirmation de chaque action.

Guide pratiqueContenu relu · 26.09.2026
Pour qui ?Utilisateurs de Workspace web

Workspace web : les commandes et les accès peuvent différer dans les applications natives.

Vérifier le compte concerné

Ce guide concerne Workspace web, pas le compte du Help Center. Ouvrez Mon compte, puis Profil ou Paramètres selon le réglage recherché. Vérifiez l’identité et l’adresse affichées avant de modifier une information.

Mettre à jour votre profil

  1. Dans Profil, contrôlez Prénom, Nom et Adresse e-mail.
  2. Complétez les autres informations pertinentes, comme Fonction, Entreprise ou Téléphone, sans publier d’informations inutiles.
  3. Sélectionnez Enregistrer le profil.
  4. Attendez Profil mis à jour, puis relisez la page. En cas d’erreur, ne supposez pas que la modification a été prise en compte.

Une modification d’adresse peut avoir un impact sur vos accès. Vérifiez les instructions retournées par le service et les messages reçus ; ce guide ne promet pas une modification simultanée des autres comptes Squared.

Régler l’apparence

Dans Paramètres, choisissez le Thème, la Densité et la Largeur du contenu. Les commandes Sidebar compacte et Réduire les animations adaptent l’affichage. Sélectionnez Enregistrer les paramètres, puis vérifiez le résultat.

Le champ de langue ou de fuseau horaire ne signifie pas que toutes les traductions ou intégrations de calendrier sont disponibles. Vérifiez le rendu réel après une modification.

Sécuriser votre accès

Dans Profil, la carte Sécurité propose les options disponibles pour votre compte. Suivez le parcours affiché pour changer un mot de passe ou ajouter une passkey. Ne générez pas de nouveaux codes de récupération uniquement pour faire un test : ce sont des informations sensibles à conserver dans un emplacement adapté.

Dans Paramètres, Sessions actives permet de consulter les appareils retournés par le service. Révoquer une autre session nécessite une confirmation ; assurez-vous d’identifier l’appareil avant d’agir.

En cas d’impossibilité

Un bloc de sécurité indisponible ne doit pas être interprété comme une désactivation de vos protections. Conservez le message exact et utilisez la récupération d’accès ou votre interlocuteur Squared. Ne transmettez jamais votre mot de passe, votre passkey ou vos codes au support.
