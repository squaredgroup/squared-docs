Utiliser les raccourcis de Workspace web

Accélérez les actions disponibles sans déclencher une commande pendant votre saisie.

RéférenceContenu relu · 26.09.2026
Pour qui ?Utilisateurs de Workspace web

Workspace web : les commandes et les accès peuvent différer dans les applications natives.

Les raccourcis documentés

Dans le portail web examiné, ⌘K ou Ctrl+K ouvre la recherche. La touche / peut également l’ouvrir lorsque le focus n’est pas dans un champ de saisie. g, puis d, permet de revenir à l’accueil en dehors des champs.

Ces raccourcis concernent la version web. Ils ne constituent pas une liste de raccourcis pour les applications natives ou pour les fonctions de votre navigateur.

Naviguer dans la recherche

  1. Ouvrez la recherche et saisissez votre terme.
  2. Utilisez les flèches pour parcourir les résultats disponibles.
  3. Appuyez sur Entrée pour ouvrir le résultat sélectionné.
  4. Utilisez Échap pour quitter le dialogue lorsque vous ne souhaitez pas choisir un résultat.

Vous pouvez toujours utiliser les boutons de l’interface : aucun raccourci n’est nécessaire pour accéder à une fonction essentielle.

Préserver une saisie en cours

Avant de changer de page ou d’actualiser, vérifiez qu’un formulaire a été enregistré. La touche Échap peut fermer une fenêtre ; prenez connaissance d’un éventuel avertissement de modifications non enregistrées. Ne supposez pas qu’une commande clavier sauvegarde automatiquement le texte.

Sur mobile et avec une technologie d’assistance

Utilisez la commande Recherche et les entrées de navigation. Avec un clavier, Tab permet de déplacer le focus vers les commandes. Si le navigateur ou une technologie d’assistance utilise le même raccourci, privilégiez le bouton visible plutôt que de modifier vos réglages de sécurité ou d’accessibilité.

Un raccourci ne fonctionne pas

Vérifiez que vous êtes dans Workspace, que le focus n’est pas dans un éditeur et qu’aucun dialogue n’est déjà ouvert. Précisez l’appareil, le navigateur et la combinaison utilisée dans votre signalement. Un conflit de raccourcis ne prouve pas que votre compte manque d’autorisations.
