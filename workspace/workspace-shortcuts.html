Raccourcis clavier

Accélérer les actions fréquentes de Workspace tout en conservant des alternatives accessibles à la souris et au tactile.

Squared WorkspaceRévision · 18.09.2026

Principes

Un raccourci doit accélérer une action connue ; il ne doit pas devenir le seul moyen de l’exécuter. Les commandes essentielles restent accessibles visuellement.

Familles de raccourcis

  • Navigation rapide vers les modules.
  • Recherche / command palette.
  • Création d’un objet.
  • Actions sur l’élément actif.
  • Fermeture ou retour.

Conflits

Évitez les raccourcis déjà réservés par le navigateur, macOS ou les champs de saisie. Les raccourcis doivent être désactivés lorsqu’un utilisateur écrit dans un input si la frappe risque d’être interceptée.

Page dédiée

La page Raccourcis de Workspace doit afficher les touches Mac de manière cohérente avec la DA, accompagnées d’un libellé clair et du contexte dans lequel elles fonctionnent.
