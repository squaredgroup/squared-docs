Utiliser les messages avec le bon contexte

Conserver les échanges utiles près du travail concerné et éviter de transformer la messagerie en stockage parallèle.

Guide WorkspaceRévisé · 24.09.2026

Quand envoyer un message

Utilisez un message pour poser une question, demander une validation ou apporter un contexte qui nécessite une conversation. Lorsqu’une information devient une action, une échéance ou une décision durable, reportez-la dans l’objet Workspace approprié.

Donner le contexte immédiatement

Indiquez le projet, la mission, le livrable ou l’action concernés. Un message comme « c’est bon ? » devient rapidement incompréhensible hors de son contexte.

Vérifier l’audience

Avant d’envoyer, distinguez échange interne et échange destiné au client. N’insérez pas dans une conversation partagée une note interne, un secret ou une information d’un autre dossier client.

Une décision ne doit pas rester uniquement dans le fil

Si un message change une date, une responsabilité, un livrable ou une tâche, mettez à jour l’objet correspondant. Le fil conserve la discussion ; Workspace doit conserver l’état opérationnel.
