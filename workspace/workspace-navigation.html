Se repérer dans votre espace

Utilisez l’accueil, le catalogue des espaces et la recherche sans perdre votre contexte.

Guide pratiqueContenu relu · 26.09.2026
Pour qui ?Utilisateurs de Workspace web

Workspace web : les commandes et les accès peuvent différer dans les applications natives.

Les points de repère

Le portail web propose un accueil, un accès aux espaces autorisés, une recherche et votre compte. Sur mobile, les entrées visibles dépendent du rôle. Un client peut notamment voir Projets et À valider ; un autre membre peut voir Travail et À traiter. Les rubriques ne sont pas identiques pour tous.

Retrouver une rubrique

  1. Depuis l’accueil, ouvrez Espaces, ou Espace selon votre navigation.
  2. Utilisez Trouver un espace… pour filtrer les rubriques accessibles.
  3. Sélectionnez le domaine recherché, par exemple Projets, Tâches ou Documents.
  4. Dans la liste, recherchez un titre et ouvrez la fiche correspondante.
  5. Utilisez Retour à la liste pour poursuivre dans le même domaine plutôt que d’ouvrir plusieurs copies de la fiche.

Un catalogue vide ou réduit ne prouve pas que les données ont été supprimées. Vérifiez votre session et les autorisations prévues pour votre mission.

Choisir le bon périmètre sur l’accueil

Les filtres Mon travail et Périmètre visible ne répondent pas à la même question. Le premier recentre sur ce qui vous concerne directement ; le second élargit aux éléments déjà accessibles dans votre environnement. Aucun filtre n’accorde de nouveaux droits.

Les éléments Sans échéance doivent être lus séparément : leur absence dans une liste organisée par date ne signifie pas qu’ils sont terminés.

Sur mobile ou avec le clavier

Sur un petit écran, passez par la barre de navigation et le catalogue des espaces. Les actions secondaires peuvent se trouver dans Autres actions. Ne concluez pas qu’une fonction a disparu uniquement parce qu’elle n’est pas placée comme sur ordinateur.

Sur ordinateur, ⌘K ou Ctrl+K ouvre la recherche. Utilisez Tab pour atteindre les commandes et Échap pour quitter un dialogue. Les raccourcis complètent la navigation, sans la remplacer.

Si une rubrique manque

Vérifiez le bon compte, revenez à l’accueil et cherchez le nom de l’espace. Si le besoin est confirmé mais l’entrée reste absente, indiquez au responsable le domaine et l’action nécessaires. Conservez le message d’erreur éventuel ; ne modifiez pas vos accès vous-même pour contourner une restriction.
