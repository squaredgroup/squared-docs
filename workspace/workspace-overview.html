Comprendre votre espace Workspace

Identifiez votre travail, vos droits et les informations qui concernent votre collaboration.

Pour qui ?Utilisateurs de Workspace web

Workspace web : les commandes et les accès peuvent différer dans les applications natives.

À quoi sert votre espace ?

Workspace rassemble les éléments de travail auxquels votre compte a accès : projets, tâches, missions, documents et échanges selon votre rôle. Il ne faut pas confondre cet espace avec le Help Center, qui contient les explications générales, ni avec une page de présentation commerciale.

Votre écran d’accueil est un point de départ. Il ne signifie pas que vous voyez toute l’activité de Squared ou tous les éléments d’un projet. Les accès, le chargement des données et les filtres déterminent ce qui apparaît.

Commencer dans le bon contexte

  1. Utilisez le parcours de connexion correspondant à votre invitation.
  2. Vérifiez votre identité depuis Mon compte. Une adresse ou un rôle inattendu doit être vérifié avant de travailler.
  3. Consultez l’accueil, puis ouvrez Espaces ou Espace pour trouver les rubriques accessibles.
  4. Ouvrez le projet ou la tâche attendu et vérifiez son titre, son responsable et les informations disponibles.
  5. En cas de doute sur votre première action, demandez au responsable de préciser la mission au lieu de modifier une fiche au hasard.

Comprendre les niveaux de travail

Un projet regroupe un objectif et ses éléments liés. Une mission décrit un périmètre de responsabilité. Une tâche correspond à une action exécutable. Un livrable est un résultat à remettre ; un document peut servir de ressource ou de référence.

Une tâche terminée n’est pas automatiquement un livrable accepté. Une notification lue n’est pas une décision. Les mots du glossaire vous aident à distinguer ces situations.

Lire avant de modifier

La lecture d’une fiche et sa modification sont deux permissions différentes. Une commande absente peut être normale pour votre compte. Ne demandez pas un rôle administrateur uniquement pour faire apparaître un bouton : indiquez plutôt l’action et l’élément concernés.

Les instructions de cette documentation décrivent le portail web vérifié dans le code. Les applications natives peuvent présenter d’autres écrans. Ne supposez pas qu’une action non disponible sur un appareil existe sur tous les autres.

Votre prochaine étape

Pour vous repérer, ouvrez Navigation. Pour avancer, consultez Projets ou Tâches. Pour une donnée manquante, utilisez le dépannage avant de recréer un élément.
