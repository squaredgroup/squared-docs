Je ne vois pas un document ou un livrable

Vérifier le contexte, la rubrique et le partage sans recréer ni écraser un fichier.

Guide pratiqueRévisé le 19 septembre 2026

Avant de modifier quoi que ce soit

Ce guide concerne un document ou un livrable que vous attendiez dans Workspace. Vous devez disposer d’un accès au bon espace et au projet concerné. Ne recréez pas un fichier pour résoudre un problème de visibilité : vous risqueriez d’introduire un doublon.

Les documents de votre projet ne sont pas les guides publics de ce centre d’aide. Un favori du forum n’est pas un fichier client.

Les vérifications à effectuer

  1. Vérifiez que vous utilisez le compte et le contexte associés au projet. Le titre ou le nom de votre interlocuteur peut aider à confirmer le bon espace.
  2. Consultez Documents, puis Livrables. Un document de travail et un résultat remis pour validation peuvent être rangés dans des rubriques différentes.
  3. Effacez la recherche du module pour revenir à la liste disponible. Dans le portail web, la recherche filtre les titres et les statuts.
  4. Vérifiez le titre et la version attendus avec l’équipe. Un fichier renommé peut ne plus correspondre au mot recherché.
  5. Si l’élément reste absent, demandez au responsable du projet de vérifier son rattachement et vos droits. Un écran vide ne permet pas, à lui seul, de conclure que le fichier a été supprimé.

Ce qu’il ne faut pas faire

Dans la version web examinée, le bouton Fichier ouvre un sélecteur de fichier pour ajouter un fichier. Ce n’est pas un bouton de téléchargement. Ne l’utilisez pas pour « ouvrir » un document existant.

Ne choisissez pas Archiver, Modifier ou Nouveau pour corriger une donnée absente. Si aucune action de consultation attendue n’est disponible dans votre version, demandez à l’équipe le bon accès de remise du livrable.

Le résultat attendu

Vous identifiez l’élément attendu avec le bon titre et la bonne version, ou le responsable confirme quel accès manque. Le simple fait de voir une rubrique n’atteste pas l’accès à tous les fichiers du groupe.

Avant de contacter le support, préparez le produit, la rubrique, le projet concerné et le message observé. Dans une demande privée, partagez seulement le minimum nécessaire. Ne publiez pas le contrat, le fichier client complet ou une URL d’accès privée dans le forum.

Retrouver mon document : dépannage guidé

Basé sur le module de données du portail web : recherche par titre/statut, rubriques et action d’ajout de fichier. Source vérifiée. Ce guide ne suppose aucune fonction de téléchargement native non vérifiée.
