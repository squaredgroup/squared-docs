Installer ou ouvrir Workspace

Choisir le portail web ou une bêta native, installer une version disponible et garder ses accès distincts.

Guide pratiqueRévisé le 19 septembre 2026

Choisir web ou application native

Le portail web Workspace s’ouvre dans un navigateur. Aucune installation de l’application native n’est nécessaire pour essayer cet accès. Le portail web et les apps natives peuvent proposer des interfaces ou des fonctions différentes.

Une bêta native nécessite une invitation et une version disponible pour votre appareil. Cette page ne promet pas qu’une distribution App Store, TestFlight ou un installateur Mac est actuellement public.

Installer une bêta reçue par invitation

  1. Ouvrez l’invitation officielle Squared sur l’appareil qui doit recevoir l’application. Ne récupérez pas un installateur depuis une discussion publique ou un site tiers.
  2. Si l’invitation utilise TestFlight, installez l’application TestFlight fournie par Apple pour l’appareil concerné.
  3. Ouvrez l’invitation, acceptez-la puis sélectionnez l’installation de la version proposée.
  4. Ouvrez Workspace et utilisez votre accès Workspace. L’installation ne remplace pas l’activation d’un espace.

Pour les étapes exactes et les versions compatibles, suivez les indications de TestFlight d’Apple et celles de votre invitation. Un compte du Help Center ne vous inscrit pas automatiquement à une bêta.

Mettre à jour ou comprendre une expiration

Consultez la fiche de l’app dans TestFlight et utilisez la mise à jour lorsqu’une nouvelle build est proposée. Une build TestFlight est disponible au plus 90 jours ; après expiration, une nouvelle build doit être fournie par l’équipe. Réinstaller la même build expirée ne prolonge pas sa durée.

Avant une réinstallation, vérifiez avec l’équipe le traitement des données locales non synchronisées. Ce guide ne garantit pas qu’elles seront conservées.

Ajouter un raccourci web sur iPhone

Dans Safari, ouvrez le portail officiel puis le menu de partage. Le guide Apple décrit l’ajout Sur l’écran d’accueil et l’option d’ouverture comme app web lorsqu’elle est proposée. Cela crée un accès web ; cela ne transforme pas le portail en application native distribuée sur l’App Store.

Guide Apple : ajouter une app web sur l’iPhone.

Lorsque l’installation échoue

Notez l’appareil, la version du système, le canal utilisé et le message affiché. Une invitation invalide, une build expirée et un mot de passe refusé sont trois problèmes différents. Utilisez le diagnostic pour préparer une demande cohérente sans transmettre l’invitation privée.
