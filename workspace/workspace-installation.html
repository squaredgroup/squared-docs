Installation

Installer et tester Squared Workspace sur iPhone, iPad et Mac selon le canal de distribution disponible.

Squared WorkspaceRévision · 18.09.2026

Plateformes

Workspace est conçu pour couvrir iOS, iPadOS et macOS. Les fonctions visibles peuvent varier selon la version de test installée, le rôle connecté et l’état du déploiement.

Version bêta / TestFlight

  1. Installer TestFlight avec l’identifiant Apple autorisé.
  2. Ouvrir l’invitation bêta reçue.
  3. Accepter le programme de test.
  4. Installer la dernière build disponible.
  5. Se connecter avec le compte Workspace activé.
Bêta

Une build TestFlight est une version de test. Signalez la plateforme, le numéro de build et les étapes précises en cas d’anomalie.

macOS

Sur Mac, utilisez uniquement le canal d’installation communiqué par Squared. Ne conservez pas plusieurs versions de Workspace actives si elles utilisent des données ou configurations différentes.

Mises à jour

Avant de diagnostiquer un bug déjà connu, vérifiez qu’une version plus récente n’est pas disponible. Après une mise à jour, relancez l’application puis reproduisez le scénario avant d’ouvrir un ticket.
