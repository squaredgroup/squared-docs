Un contenu CMS ne s’affiche pas

Suivre la chaîne collection, item, dataset et page dynamique avant de modifier des données.

Guide pratique5 min
Quand utiliser ce guide

Un élément existe dans le CMS mais manque sur une page du site.

Les étapes à suivre

  1. 01

    Trouver la source

    Confirmez la bonne collection et le bon item. Vérifiez que les champs nécessaires sont remplis et que les références pointent vers les éléments attendus.

  2. 02

    Lire la connexion

    Sur la page concernée, identifiez le dataset et ses filtres. Un filtre ou une connexion peut masquer un item sans que les données aient disparu.

  3. 03

    Contrôler la page dynamique

    Si une page dynamique est utilisée, comparez le slug, l’item associé et les champs connectés. Un modèle correct avec un item différent peut produire un résultat trompeur.

  4. 04

    Comparer Preview et live

    Vérifiez le rendu dans Preview puis sur le site publié. Ne renommez pas un field key et ne modifiez pas la structure de la collection comme première tentative.

Résultat attendu

Vous avez identifié à quel niveau l’item cesse d’être visible : données, référence, dataset ou publication.

Si le problème continue

Si un dataset, un champ technique ou une page dynamique doit changer, demandez une validation structurelle avec la collection, l’item et l’URL concernés.
