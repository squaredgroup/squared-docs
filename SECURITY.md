# Politique de sécurité

## Ne pas signaler une vulnérabilité dans une Issue publique

Si vous découvrez un problème de sécurité ou une information sensible exposée, **ne créez pas d’Issue ni de Discussion publique contenant les détails exploitables**.

Utilisez le canal officiel Squared Group via https://www.squaredgroup.studio/.

## Informations à ne jamais publier

- mots de passe ;
- tokens ;
- clés API ;
- secrets de signature ;
- données personnelles ou clients ;
- informations d’infrastructure privées ;
- captures contenant des informations confidentielles.

## Secret exposé

Un secret publié doit être considéré comme compromis. La priorité est de le révoquer ou le régénérer, puis de nettoyer sa trace publique.
