Comment interpréter cette page

Le statut évite d’afficher une disponibilité fictive.

Opérationnel

Test réussi

Le composant a répondu correctement au monitor serveur. Pour un site externe, cela valide sa disponibilité réseau depuis l’infrastructure de monitoring, pas l’intégralité de ses fonctions internes.

Partiel

Test incomplet

Le service répond, mais certaines fonctions demandent une session ou ne peuvent pas être entièrement vérifiées publiquement.

Indisponible

Test échoué

Le composant n’a pas répondu dans le délai attendu ou a retourné une erreur.

Un service semble indisponible ?

Ouvrez une demande avec l’heure, le service concerné, votre navigateur et le message d’erreur observé.
