# Roadmap éditoriale — Squared Help Center

Version : 26 septembre 2026

## P0 — autonomie essentielle
Orientation Squared ; connexion ; support privé ; démarrage client ; feedback client ; documents/livrables ; compréhension d’une mission ; blocage/retard ; remise pour validation ; navigation Workspace ; suivi projet ; tâches.

## P1 — collaboration de bout en bout
Transmission de contenus, changements de périmètre, planning, messages, notifications, invitations, fin de projet, fin de mission, transfert des responsabilités.

## P2 — produits et références
Assistance Squared Build lorsque les parcours réels sont stabilisés ; enrichissement Wix Studio, Design System, développement et sécurité selon les usages réels.

## Gouvernance
Statuts : à auditer → à compléter → à vérifier → prêt → publié → à revoir.
Chaque article doit avoir un public, un owner éditorial, une date de dernière vérification et, lorsque pertinent, une version produit vérifiée.

## Anti-doublon
Les guides HTML versionnés restent dans GitHub. Les articles administrables servent aux contenus gérés depuis le Help Center. Ne pas maintenir deux copies concurrentes d’un même contenu.
