Suivre une demande privée

Compléter une demande existante sans disperser les informations.

Continuez dans la demande existante

Si le problème est le même, ajoutez les nouvelles informations au ticket existant plutôt que d’en ouvrir plusieurs. Cela conserve le diagnostic, les pièces utiles et les décisions au même endroit.

Lorsque l’équipe vous demande une précision

Répondez au point demandé avec le minimum nécessaire : produit, action, résultat observé, message exact ou pièce utile. Ne transmettez jamais mot de passe, passkey, code de récupération ou secret.

Le problème a changé

Expliquez ce qui est désormais différent. Si le nouveau sujet est indépendant, une demande séparée peut être plus claire.

Retrouver vos demandes

Utilisez Mes tickets lorsque vous êtes connecté au Help Center.
