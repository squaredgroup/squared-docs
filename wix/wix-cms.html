Wix Studio — CMS & données

Collections, champs, références, datasets et pages dynamiques dans une logique sûre.

GuideMis à jour · 18.09.2026

Collections

Une collection structure des données réutilisables. Modifier une valeur est différent de modifier le modèle de données : ajouter, supprimer ou renommer un champ est une intervention structurelle.

Champs

Respectez le type du champ et son identifiant technique. Un field key peut être utilisé par des datasets ou du code même si son nom affiché semble modifiable.

Datasets

Le dataset relie la collection aux éléments de la page. Modifier filtre, mode ou connexion peut changer plusieurs écrans et doit être traité comme N3.

Pages dynamiques

Une page dynamique est un template alimenté par un item CMS. Vérifiez slug, item, dataset, filtres et champs connectés avant de modifier le design.

Checklist

  • Bonne collection.
  • Bon item.
  • Champs requis remplis.
  • Références correctes.
  • Slug cohérent.
  • Preview desktop/mobile.
