Wix Studio — Responsive

Breakpoints, cascade, overrides et méthode de contrôle pour éviter les corrections fragiles.

GuideMis à jour · 18.09.2026

Breakpoints

Travaillez du desktop vers les tailles plus petites. Un override tablette peut se propager vers mobile, tandis qu’un override mobile reste local au mobile.

Changements globaux

Remplacer une image, changer un lien, supprimer un élément ou modifier son parent n’est pas un simple override visuel : l’impact peut être global.

Procédure

  1. Desktop principal.
  2. Réduire progressivement le canvas.
  3. Corriger tablette seulement si nécessaire.
  4. Vérifier mobile et zones tactiles.
  5. Tester les largeurs intermédiaires.
  6. Preview.

À éviter

  • Dupliquer une section pour mobile.
  • Utiliser des marges extrêmes.
  • Déplacer au pixel sans comprendre le parent.
  • Supprimer un élément pour le masquer sur un seul breakpoint.
