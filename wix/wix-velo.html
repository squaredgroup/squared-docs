Wix Studio — Velo & code

Comprendre les risques liés aux IDs, aux champs CMS et au code Velo avant toute intervention.

GuideMis à jour · 18.09.2026

À quoi sert Velo

Velo ajoute de la logique JavaScript aux sites Wix. Un élément visuel peut donc être utilisé par du code même si rien ne l’indique dans le canvas.

Risques principaux

  • Renommer un ID casse une référence $w(...).
  • Supprimer un élément peut supprimer une fonctionnalité.
  • Renommer un field key peut casser une requête.
  • Modifier un fichier de code peut affecter plusieurs pages.

Avant de modifier

  1. Identifier le scénario exact.
  2. Rechercher les références de l’élément/champ.
  3. Prévoir un retour arrière.
  4. Tester hors production si possible.
  5. Contrôler la console.

Règle Squared

N3 — réservé

Ne jamais tester une correction de code directement sur un site de production sans validation et sans scénario de rollback.
