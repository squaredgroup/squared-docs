Wix Studio — Vue d’ensemble

Comprendre l’interface, la structure d’une page et les règles Squared avant toute modification.

GuideMis à jour · 18.09.2026

Interface essentielle

Le panneau gauche regroupe pages, calques, CMS, médias et outils. Le canvas représente le breakpoint actif. L’inspecteur contrôle dimensions, layout, design et interactions.

Structure d’une page

Une page propre suit une hiérarchie : page → section → layout → container → élément. Plus cette hiérarchie est logique, plus le responsive est fiable.

Règles avant modification

  • Identifier page et breakpoint.
  • Vérifier le parent dans les calques.
  • Ne jamais supprimer un élément sans vérifier CMS/code.
  • Preview avant Publish.
  • Contrôle live après publication.

Niveaux d’intervention

N1 : contenu. N2 : design/comportement. N3 : architecture, code, permissions, domaine.
