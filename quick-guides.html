Guides rapides

Procédures courtes pour exécuter les actions les plus fréquentes sans parcourir un guide complet.

GuideMis à jour · 18.09.2026

Publier une modification Wix

  1. Identifier la page et le breakpoint.
  2. Faire la modification minimale.
  3. Vérifier desktop, tablette et mobile.
  4. Tester les liens et interactions concernés.
  5. Utiliser Preview.
  6. Obtenir la validation N2/N3 si nécessaire.
  7. Publier puis contrôler la version live.

Voir le guide complet →

Corriger un problème responsive

  1. Identifier le parent de l’élément.
  2. Vérifier stack/grid/container.
  3. Comprendre l’override avant de changer une valeur.
  4. Tester les largeurs intermédiaires.
  5. Éviter toute duplication de section comme faux correctif.

Voir le guide complet →

Corriger un lien cassé

  1. Vérifier l’URL cible.
  2. Contrôler protocole, slug et ancre.
  3. Tester dans Preview.
  4. Tester après publication.
  5. Si l’URL publiée change, vérifier le besoin de redirection.

Signaler un incident

  1. Produit et page concernés.
  2. Action réalisée.
  3. Résultat obtenu.
  4. Résultat attendu.
  5. Message d’erreur exact.
  6. Capture uniquement si utile.

Voir la procédure incident →

Publier une information dans le Help Center

  1. Vérifier qu’elle peut être publique.
  2. Retirer noms clients, secrets et données privées.
  3. Utiliser un titre clair et une procédure reproductible.
  4. Ajouter les liens de référence utiles.
  5. Mettre à jour le changelog si la règle est structurante.
